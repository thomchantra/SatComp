# Factory presets

Every `*.json` file in this folder is embedded into the plug-in at build time and listed under FACTORY
in the preset dropdown (sorted by file name; `INIT` is always first and built in).

Format: `{ "format": "satdiff-preset", "version": 1, "name": "...", "params": { "<param id>": <value>, ... } }`.
Parameter ids are the ones in `src/params.rs` (generated by `tools/gen_dparams.py`). Missing ids fall back to the default.
Bypass is never stored. `lim_on` is 1 (limiter on) / 0.
