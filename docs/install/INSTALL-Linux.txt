@NAME@ @VER@ - installation (Linux, experimental)
=================================================

This Linux build is new and lightly tested. Feedback is very welcome (see "Got issues?" below).

This zip contains two plug-in formats (VST3 and CLAP). The VST3 is a FOLDER, not a single file.

Easiest: the install script
---------------------------
1. Unzip the download and open a terminal in the unzipped folder.
2. Run:   bash install.sh
   It copies both formats into your home folder (~/.vst3 and ~/.clap). Add --system to install
   for all users instead (it asks for your password).
3. Rescan plug-ins in your host (REAPER: Options > Preferences > Plug-ins > VST/CLAP > Re-scan)
   or restart it. The plug-in appears as "@NAME@".

By hand
-------
~/.vst3 and ~/.clap are HIDDEN folders (names starting with a dot). In your file manager press
Ctrl+H to show hidden files, and create the folder if it does not exist yet.
  VST3: copy the whole folder  VST3/@PLUGIN@.vst3  into  ~/.vst3/
        (for all users: /usr/local/lib/vst3/)
  CLAP: copy  CLAP/@PLUGIN@.clap  into  ~/.clap/
        (for all users: /usr/local/lib/clap/)

Needs an X11 session (the window is drawn through X11 and OpenGL). The manual button opens the
PDF with your default viewer (xdg-open).

Your settings and presets
-------------------------
  Presets:  ~/.config/@NAME@/Presets
  Themes:   ~/.config/SatComp/themes.json   (shared by SatComp, SatXComp and SatLim)

Uninstall: delete the files you copied.


Got issues?
-----------
Found a bug, or something sounds or looks odd? Please submit a bug report on GitHub:
  https://github.com/thomchantra/SatComp/issues
Say which plug-in and version, your host (DAW) and operating system, and what you did. A screenshot
or a short description of how to reproduce it helps a lot.
