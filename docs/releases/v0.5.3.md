A housekeeping release: no new features and no change to the sound or the look. The code was reorganised so the engine and UI can be shared by the upcoming SatXComp and SatEQ plug-ins.

## Changed
- **Engine split into blocks.** The saturator, compressor, sidechain key input and EQ stages are now separate, reusable pieces; the SatComp engine only wires them together. Rendering 101 test scenarios (every shaper and oversampling mode, compressor, EQ, sidechain, bypass, delta, gain match, automation, other sample rates) through v0.5.1 and v0.5.3 gives bit-identical audio and meter values.
- **Shared UI toolkit.** The drawing canvas, colour schemes, fonts and the slider/button widget kit moved into their own crate. A scripted 460-frame render of the editor (sliders, EQ page, About, Appearance, menus, scope, presets) draws identically to v0.5.1.
- The About > Changelog page has a v0.5.3 entry.

## Notes
- Parameter ids, presets, projects and `themes.json` are unchanged: a v0.5.1 preset or project loads the same.
- AU is shelved for now (no demand yet).
- CPU use is unchanged within measurement noise (about 0.3-0.7% of one core at 48 kHz).

Full changelog: https://github.com/thomchantra/satcomp/compare/v0.5.1...v0.5.3
