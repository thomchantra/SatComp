Fixes a loud thump when the plug-in is switched on, and adds an Appearance tab with custom themes, six fonts and a waveform scope.

## Fixed
- **Thump when the plug-in is enabled or the window regains focus.** Some hosts rebuild the plug-in's audio engine every time the FX is switched on; the new engine used to glide from default settings to yours, which was audible as a loud spike. It now starts at your settings.
- The audio thread no longer waits on the custom-waveshaper lock while you draw a curve.

## New
- **Appearance tab** (About page, between About and Changelog): a dark/light switch, a scrollable scheme list with swatches, and a font choice (Fira Code, JetBrains Mono, Geist Mono, Roboto Mono, Oxygen Mono, Doto).
- **Custom themes:** a theme editor with an HSV colour picker and a live preview on a static copy of the plug-in. Name and hex entry use an on-screen keyboard, because some hosts (REAPER) take typing in plug-in windows as hotkeys. Themes are saved in `~/Library/Application Support/SatComp/themes.json` (`%APPDATA%\SatComp\themes.json` on Windows) and the active one is stored in the project.
- **Waveform scope (transient meter):** click the icon in the corner of the compressor plot. Half or full wave output in the UI colour with the gain reduction stacked on top in the accent colour. Drag the view to change the time window (250 ms to 8 s) and the ceiling (+2 dB to -14 dB, so overshoots above 0 dB stay visible); SRC, WAVE, WIN and CEIL are also in a row under the plot.
- The colour schemes Sulfur and Matcha were replaced by Genesis and Suika (same slots).
- The oversampling OFF button now reads x1.

## Notes
- Windows and the new theme editor are lightly tested.
- With several editor windows open the GUI redraw cost adds up; this is on the to-do list.
