Sidechain input and light mode for every colour scheme.

## New
- **Sidechain input:** an external key from a second stereo input, with key gain, HP and LP filters, a SOLO to listen to the key, and KEY MIX to blend it with the main signal (KEY MIX takes the place of FF>FB while the sidechain is on).
- **Light mode for all colour schemes:** double-click the header icon, or use the scheme menu. There are now 20 schemes, each with a dark and a light version.
- **Scrolling About and Changelog text boxes** with a draggable scroll bar.
- The saturator and sidechain low-pass filters now reach down to 200 Hz.

## Notes
- Projects saved with an older version keep their colour scheme (it is migrated once on load).
- The sidechain is shown as a button that turns red when it is switched on but the host has not given the plug-in a sidechain bus.
