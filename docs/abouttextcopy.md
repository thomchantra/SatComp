SatXComp about copy
===
A 4-band compressor with waveshaping saturator and 5-band EQ. For surgical baking intentions :3

Set crossover range with X-OVR sliders with 12dB, 24dB, 48dB, and 96dB slope options, then drive each band to taste.

Use Sidechain mode for dynamic EQ style ducking, then cook hard with waveshaping distortion.
[LMB] Top-right pencil icon enters custom draw mode.
[LMB] Lower-right SAT value triggers auto-gain match.

Generally slower Attack and Release is ideal for low freq, faster Attack and Release for high freq

Refine tone with post-compressor 5-band EQ, or sculpt with notch, bandpass and allpass with dry signal blending.

SatLim about copy
===
A 2-stage clipper/limiter with waveshaping saturator
When you need to nuke it from orbit B)

Use Tube with low Drive for warm saturation, opt for destruction with Tri-fold, or annihilate with custom asymmetric waveshape.
[LMB] Top-right pencil icon enters custom draw mode.
[LMB] Lower-right SAT value triggers auto-gain match.

Turn on Lookahead for brickwall, true peak limiting.
Lowering Threshold chews the input signal deeper.
Clip exposes and bricks more transients in the mix.

Balance between Threshold (limiter) and Clip (clipper) to dial in desired loudness and character.

Shorter Release gives a denser, punchier compression whilst introducing distortion artifacts, longer Release gives a smoother result with lower distortions.

**== Transient/GR Meter ==**
[Solid]   Limiter Gain Reduction
[Striped] Clipper Gain Reduction
